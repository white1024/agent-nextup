IPC commands

The Tauri IPC surface between the UI and the core engine.

The UI talks to the core engine over Tauri IPC, passing lightweight DTOs and state diffs only. Heavy I/O always runs on a blocking thread pool so the UI thread is never blocked.

Events pushed the other way: workspace://changed (debounced 400 ms), ledger://appended (the ledger grew — the notification layer reads the tail), and terminal://output|exit|sessions (PTY streams; output carries a sequence number, sessions covers pop-out switching).

Desktop integration1 command
open_folderraises the OS file manager on a folder, behind the path shown in the app. Directories only, checked against the filesystem: the same call handed a file would launch its default application, so the check is what keeps this from being a way to run a program.
Application lifecycle3 commands
quit_appwhere the close button goes. On macOS it sends AppKit’s terminate:, because tearing down the last window and then the process is the one shutdown sequence that crashes there; Windows and Linux exit directly, which is what closing the last window already did.
update_preflight
update_relaunch
— the app’s half of the in-app update; checking, downloading, verifying and installing belong to the updater plugin. The preflight reports whether this is the Windows portable build (no in-app install — its installer would add a second copy), whether the bundled hub is held open by another process (Windows will not replace a running executable), and how many terminal sessions an install would end. The relaunch starts the new version after a macOS or Linux install — through terminate: on macOS, for the same reason as quit_app; the Windows installer restarts the app itself.
